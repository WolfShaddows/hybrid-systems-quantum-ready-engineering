# Example experiment: Bell state

`bell_state.py` prepares H+CNOT, measures both qubits, and simulates 2,048 shots. This is a starter example, not a published result. Create an isolated environment, install Qiskit and Aer from official instructions, record versions, run `python bell_state.py`, and add output to a copy of `results/EXPERIMENT-TEMPLATE.md`. Ideal outcomes are 00 and 11; finite counts fluctuate.
